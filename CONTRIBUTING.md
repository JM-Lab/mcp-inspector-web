# Contributing

Thanks for taking a look. This project is kept small and is maintained by one person, so it works a little differently from most open source projects.

## Bugs: open an issue

Use the [bug report form](https://github.com/JM-Lab/mcp-inspector-web/issues/new/choose). The most useful reports have:

- The server address, if it is public (otherwise, what kind of server and transport it is)
- What you did, what you expected, and what you saw
- The browser and version
- The messages from the **History** tab, and any errors in the browser console

If a server cannot be reached, check [what a server needs to be reachable](README.md#what-a-server-needs-to-be-reachable) first. A server that does not allow CORS cannot be reached from any web page, and that is not a bug here.

## Ideas and questions: use Discussions

Feature ideas, questions and "how do I" go to [Discussions](https://github.com/JM-Lab/mcp-inspector-web/discussions), not issues.

## Pull requests are not accepted

Pull requests are closed automatically. This is not about the quality of anyone's work: keeping every change in one hand keeps the code small and its direction consistent. If you need a change now, the MIT license lets you fork it and change anything.

## Security

Please do not open a public issue for a security problem. Use [private vulnerability reporting](https://github.com/JM-Lab/mcp-inspector-web/security/advisories/new) instead.
